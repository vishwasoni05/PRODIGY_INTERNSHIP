# PRODIGY_INTERNSHIP
Data Science Intern at Prodigy – Working on data cleaning, EDA, visualization, and basic machine learning models. Gaining hands-on experience in Python, analyzing datasets, extracting insights, and presenting results. Strengthening my skills in real-world data-driven problem solving.

⚡ **Data Science & Machine Learning Project Showcase**

A collection of beginner-friendly yet impactful data science mini-projects covering visualization, machine learning, sentiment analysis, and real-world pattern detection.
Each task is designed to build practical skills while keeping the learning process engaging and insightful.

📊 **TASK 1: Data Visualization with Bar Charts & Histograms**

Starting off with visual exploration!
This task transforms raw data into easy-to-interpret visuals using bar charts and histograms. Whether you're analyzing age groups, category frequencies, or numeric distributions, these plots help you instantly understand your dataset and spot key trends.

🧽🕵️ **TASK 2: Data Cleaning & EDA (Titanic Dataset)**

Clean data = smart insights.
In this task, the Titanic dataset is cleaned and explored to uncover meaningful patterns. Missing values are handled, feature relationships are examined, and visualizations reveal how factors like age, gender, and passenger class relate to survival outcomes.
A solid introduction to real-world data preparation and exploration.

🌲📈 **TASK 3: Decision Tree Model – Customer Purchase Prediction**

This task builds a decision tree classifier using the Bank Marketing dataset to predict whether a customer will subscribe to a service.
Key steps include:

* Data preprocessing and encoding
* Building and interpreting the decision tree
* Evaluating model accuracy and performance

A great way to understand model decisions through clear, tree-based logic.

🗣️💡 **TASK 4: Sentiment Analysis on Social Media Text**

Ever wondered what people really feel online?
This task processes social media posts to identify sentiment trends—positive, negative, or neutral. Through text cleaning, sentiment scoring, and insightful visualizations like bar charts and word clouds, the analysis highlights public mood around topics, brands, or events.

🚨🛣️ **TASK 5: Traffic Accident Trend & Hotspot Detection**

An analytical dive into road safety data.
This task examines accident records to find patterns based on weather, time, road conditions, and location. Visual tools such as heatmaps and hotspot maps help identify high-risk zones and contributing factors, making it useful for safety planning and policy insights.
